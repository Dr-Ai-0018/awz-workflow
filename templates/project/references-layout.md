## Reference Library 边界

1. 本文件：人工维护的项目背景、规范、设计稿、数据说明、论文、网页和证据索引。
2. `.awz/references.json`：可提交、机器无关的外部源码映射，只保存 id、用途和 required 等声明。
3. `docs/references/reference-context.md`：由 AWZ Reference Library 生成的本机解析结果，包含 clone 路径、revision、license、trust 和 `readFirst`；不要手工维护。

第三方源码 clone 始终放在机器级 AWZ References，不复制进本目录。URL 不得携带凭据；大文件、截图和导出物放 `temp/`，这里只保留索引与必要摘要。适合跨机器长期共享的结论应提升到 README、正式文档或 ADR。

公开启动、测试和构建命令只在 `README.md` 或正式运行文档维护，本文件链接它们但不复制，避免命令漂移。
